# OpenCortex Landing Page

Static marketing front door for OpenCortex.

## Files

- `index.html` — landing page markup
- `styles.css` — landing page styling

## Deploy notes

Recommended path on Vercel:

1. Import this repo into Vercel.
2. Set the project **Root Directory** to `site`.
3. Deploy as a static site.

The page uses absolute GitHub links for the benchmark report and repo so it still works when only `site/` is deployed.
